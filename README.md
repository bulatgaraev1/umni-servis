# umni-servis

Статический сайт проекта «Умный Сервис». Чистый HTML/CSS/JS, без сборщика — файлы отдаются как есть.

## Структура

- `*.html` — страницы сайта (13 шт., точка входа — `index.html`)
- `style.min.css` — боевые стили (подключены во всех страницах)
- `new.css` — доп. стили (только `case-1.html`)
- `js/main.min.js` — боевой JS (подключён во всех страницах)
- `img/`, `fonts/`, `favicon/` — ассеты
- `style.css`, `js/main.js` — несжатые исходники (в проде НЕ используются; при правках редактировать их, затем переминифицировать в `.min`)
- `slick.min.js`, `jquery.custom-select.js` — не подключены напрямую (функционал в `main.min.js`), оставлены как есть

## Деплой

Хостинг: reg.ru (shared, загрузка по FTP). Сайт — статика, поэтому деплой = загрузка файлов в корень домена на хостинге.
FTP-доступы берутся в панели reg.ru. Пароли и ключи в репозиторий не коммитить (см. `.gitignore`).
